# 回测区间差异分析：动量策略的市场方向依赖

> 生成时间: 2026-05-23

---

## 现象

同一策略在两个相邻回测区间表现天壤之别：

| 指标 | 3月 (3/1→4/1) | 4-5月 (4/1→5/15) |
|------|---------------|-------------------|
| 交易日 | 23 | 29 |
| 总交易笔数 | 51 | 121 |
| 日均交易 | 2.2 | 4.2 |
| 胜率 | 9.8% | 44.6% |
| 平均收益率 | -1.47% | +0.24% |
| 累计收益率 | **-74.8%** | **+29.6%** |
| 平均盈利 | +2.10% | +1.98% |
| 平均亏损 | -1.86% | -1.15% |
| 最大回撤 | 53.3% | 19.8% |
| 夏普比率 | -10.32 | +1.67 |
| 最长连亏 | 15 | 11 |

---

## 根因分析

### 策略本质：动量延续押注

本策略买入"尾盘走强的股票"，T+1次日退出。核心假设是：**尾盘的强势会在次日延续**。

但在不同市场环境下，这个假设的成立概率完全不同。

### 3月：下跌/震荡市

- **候选池萎缩**：能通过 K 线筛选（2/4 阳线 + ATR 适中）的股票大幅减少，日均仅 2.2 笔
- **动量易中断**：弱势市场中阳线是"反弹"而非"趋势"——少数还在涨的股票，次日低开概率高
- **阴跌模式**：大量交易以 -1%~-2% 的 next_open 退出，没触及 -5% 止损线，但持续小额亏损
- **止盈触发少**：下跌市中日振幅偏窄，+5% 止盈难以触发

### 4-5月：上升市

- **候选池充足**：日均 4.2 笔交易，K 线通过率翻倍
- **趋势延续性强**：尾盘走强 → 次日高开，动量在上升市中成立
- **止盈频繁触发**：趋势行情中日振幅大，+5% 止盈线更易触及
- **亏损收敛**：强市中即使回调，幅度也较小（-1.15% vs -1.86%）

### 关键证据：平均盈利几乎相同

两段时间的**平均盈利（+2.10% vs +1.98%）几乎一样**，说明策略"赌对了"的时候收益水平是稳定的——问题出在"赌对的频率"上。

胜率从 9.8% → 44.6%，不是策略变好了，是**市场环境让假设成立的概率变了**。

---

## 结论

这不是策略失效，而是**动量策略的固有特征**：

- 趋势市中策略赚钱（动量延续假设成立）
- 震荡/下跌市中策略亏钱（动量延续假设不成立）

任何一个 T+1 尾盘策略都无法回避这个周期性。回测的价值恰恰在于揭示了这种依赖关系。

---

## 可能的缓解方向

### 1. 大盘趋势过滤（最直接）

指数在 MA20 下方时空仓，仅在上升趋势中交易。

```
if index_close < MA20: skip_day()
```

**代价**：可能错过指数反弹初期的尾盘机会，但能避开大部分下跌市的亏损。

### 2. 板块轮动维度

当前策略对所有板块一视同仁。弱势市场中板块分化明显——只做当日板块排名前 3 的板块内股票，避开弱势板块中的"补涨陷阱"。

### 3. 动态仓位

弱势市中降仓到 2-3 只，强势市保持 5 只。可以用指数 MA20 斜率或 VIX 类指标作为仓位系数。

### 4. 放宽止损 + 紧收止盈

下跌市中 -5% 止损可能太宽，让 -1~-2% 的小亏累积成大亏。可以考虑动态调整：
- 弱势市: 止损 -3%, 止盈 +3%
- 强势市: 止损 -5%, 止盈 +5%

但过度优化止损止盈有曲线拟合风险，需要足够长的回测区间验证。
