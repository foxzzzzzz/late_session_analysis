# 回测 vs 实盘策略差异汇总

> 生成时间: 2026-05-23

---

## 一、回测核心设计原则

回测的定位是**纯规则策略的历史验证**，而非实盘的完整复刻。以下差异中，大部分是**有意为之**的不对齐（因数据不可得或需要避免未来信息偏差），少数是**阈值有意不同**（因信息维度不对等）。

---

## 二、完全对齐的部分

以下筛选逻辑在回测和实盘中完全一致：

| 层级 | 内容 | 说明 |
|------|------|------|
| L1 | 基础准入 | 成交额>5000万、换手率>1%、价格5-100元、排除ST/停牌/涨停 |
| L2 | 尾盘异动检测 | 量比≥1.2、最后5分钟量≥5%、尾盘拉升/企稳/突破形态 |
| L2 | 资金流向 | require_capital=True（回测中has_capital_data=False→不生效，当pass数不足时自动放宽） |
| L3 | 技术验证 | require_above_ma=True、历史胜率、波动率、板块排名 |
| L3 | K线形态 | ATR范围、连涨天数、涨幅频率、单日涨幅等7项R1+6项R2 |

## 三、参数级差异（有意调整）

### 3.1 K线筛选阈值

| 参数 | 实盘值 | 回测值 | 原因 |
|------|--------|--------|------|
| `min_yang_ratio_4d` | 0.75 (3/4) | **0.50** (2/4) | 实盘追求高胜率；回测放宽以获取更多样本评估策略 |
| `min_consecutive_close_rise` | 3天 | **2天** | 同上，避免震荡行情中无信号 |

可通过 `BT_KLINE_MIN_YANG_RATIO_4D`、`BT_KLINE_MIN_CONSECUTIVE_CLOSE_RISE` 等环境变量覆盖。

### 3.2 L4 评分阈值

| 参数 | 实盘值 | 回测值 | 原因 |
|------|--------|--------|------|
| `l4_strong_buy` | 85 | **35** | 回测无资金流数据（C维度20分全为0），分数天花板~65 |
| `l4_buy` | 75 | **25** | 实盘85/75/60在完整5维100分制下校准，不适用于回测 |
| `l4_watch` | 60 | **15** | |

可通过 `BT_L4_STRONG_BUY`、`BT_L4_BUY`、`BT_L4_WATCH` 环境变量覆盖。

## 四、数据源差异（不可修复）

| 差异项 | 实盘 | 回测 | 影响 |
|--------|------|------|------|
| **资金流向** | 新浪/东财实时API → big_order_net、active_buy_ratio | 无（capital_flow_mode="none"） | C维度20分永远为0，L4分数整体偏低 |
| **盘口数据** | pytdx L2行情 → bid_ask_ratio、cancel_rate | 无 | require_orderbook=False，不影响通过率 |
| **概念热度** | 同花顺概念分析 → concept_score | 无（概念回退为数量×1.5） | E维度概念分子仅有基础分 |
| **北向情绪** | 同花顺hsgtApi实时 | 历史日线数据预加载（收盘后的滞后数据） | 仅当日终值，无盘中动态变化 |
| **5分钟线** | 实时push（Tencent API） | baostock历史5分钟线（全量，含14:50-15:00） | 回测有更完整的尾盘数据 |
| **S0板块预筛选** | 同花顺涨幅排序→Top 3-5板块 | skip_s0=True，直接用TARGET_SECTORS固定板块 | 回测用固定板块成分股作为候选池 |

## 五、流程差异

| 差异项 | 实盘 | 回测 |
|--------|------|------|
| **股票池来源** | S0动态板块预筛选（~500只） | 固定板块成分股（~1200-2000只） |
| **S2时间窗口** | 14:30-14:55 循环扫描 | 一次性加载全天5分钟线，截断到14:59 |
| **L3富化** | 同花顺限售解禁+板块排名 | 仅板块排名（无解禁数据） |
| **LLM分析** | LLM占30%权重（35并发/15s超时） | 无（llm_results={}，rule_weight=1.0） |
| **资金流富化** | S3之后max_capital_enrich=300只 | 无 |
| **退出机制** | 人工决策 | T+1自动化：止损(-5%) > 止盈(+5%) > 次日开盘价 |
| **滑点/佣金** | 无（实盘按实际成交） | 买卖各5bps滑点 + 0.025%双向佣金 |
| **报告** | Jinja2 Markdown + 可选PNG | CSV + JSON + Markdown |

---

## 六、风险控制（回测独有）

| 参数 | 值 | 说明 |
|------|-----|------|
| `stop_loss_pct` | -5.0% | 次日最低价触及买入价×0.95 → 止损退出 |
| `take_profit_pct` | +5.0% | 次日最高价触及买入价×1.05 → 止盈退出 |
| 优先级 | 止损 > 止盈 > 次日开盘 | 模拟日内最差情况优先 |

---

## 七、回测专属能力

| 能力 | 说明 |
|------|------|
| 日线缓存 | parquet格式，按日期范围自动校验有效性 |
| 非交易时段优化 | 自动跳过akshare，直接使用baostock |
| 环境变量覆盖 | 所有阈值可通过`BT_*`环境变量覆盖，不改代码 |

## 八、环境变量速查

```bash
# K线阈值（回测默认比实盘宽松）
BT_KLINE_MIN_YANG_RATIO_4D=0.50        # 实盘: 0.75
BT_KLINE_MIN_CONSECUTIVE_CLOSE_RISE=2  # 实盘: 3

# L4阈值（回测默认比实盘低）
BT_L4_STRONG_BUY=35   # 实盘: 85
BT_L4_BUY=25          # 实盘: 75
BT_L4_WATCH=15        # 实盘: 60

# 日常使用
BT_START_DATE=20260401  # 回测起始日期
BT_END_DATE=20260515    # 回测结束日期
BT_NO_CACHE=true        # 禁用缓存
```
