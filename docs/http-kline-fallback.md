## 数据与限制

- 指数显式使用sh000001，避免误取sz000001平安银行。新浪指数日线实测仅到昨日收盘，判定基于可获得的已完成日线，不等同于TDX含当日未收盘bar的口径。日志明确记录末条日期。
- 新浪volume为股，保留原单位；该接口不提供成交额，close乘volume为估算值，标记amount_estimated。不得当成真实资金流向，资金流数据获取路径未改变。
- HTTP分钟线仅保留今日、当前5分钟边界及以前的bar；校验价格、数值、时间重复、交易时段、从开盘到末条的连续性和时效。缺口或过期返回None，不补零或插值。管线原有未完成bar剔除逻辑仍生效。
- 指数至少25根，拒绝未来日期及超过配置自然日延迟的数据。未新增交易日历；长假、停牌与稀疏成交股票可能被拒绝，需结合日志验收。
- HTTP有请求超时和并发上限，不做内部重试；不是整个批次的总耗时上限。全部HTTP源也失败时仍可能无推荐，日志会明确显示缺数据数。
- 可调参数及含义在.env.example：HTTP_KLINE_TIMEOUT、HTTP_KLINE_WORKERS、HTTP_INDEX_MAX_AGE_DAYS、HTTP_5MIN_FETCH_BARS、HTTP_5MIN_MAX_LAG_MINUTES。未配置也使用同样默认值；服务器原.env不需要替换。

## 本地验证

先定义及验证测试：HTTP正常/超时、陈旧/未来指数、分钟过期/重复/无效价格/缺口/延迟拒绝、指数沪市路由、量单位、TDX部分缺失只补缺失、无TDX仍走HTTP、TDX成功不触发HTTP。

相关94项测试通过（HTTP、指数、K线、管线、服务器池、诊断工具）。实际执行tools/verify_http_fallback.py，在独立进程强制TDX不可用：指数50根，末条2026-10-29；10只沪深股票全部获取今日17根分钟线，截至2026-10-30 10:55。验收结果位于本地tmp/http-fallback-acceptance-20261030.json。此时尚未到尾盘，真实尾盘信号效果未验证；尾盘指标计算由已有及新增数据路径测试覆盖，不保证产生推荐或收益。

## 云端验收

2026-10-30 11:06:54独立进程验收PASS：指数50根截至10月29日；10只股票各19根分钟线，09:35至11:05，全部标记sina_http。上午尾盘指标为0不代表失败；price_at_1430为既有函数用最新价格占位，并非未来价格。该结果验证取数路径，14:35真实管线覆盖率和耗时仍待验收。

同步已验证源码后，在服务器项目目录执行；无需运行交易管线或改变市场防抖状态：

```bash
mkdir -p tmp
.venv/bin/python tools/verify_http_fallback.py \
  --codes 000001 600519 600000 000858 300750 601318 002594 600036 000333 601166 \
  --output tmp/http-fallback-cloud.json \
  > tmp/http-fallback-cloud.log 2>&1
cat tmp/http-fallback-cloud.log
```

这是独立进程强制HTTP降级验收，指数和全部测试代码成功才显示PASS，并以非零退出码报告失败。非交易日不提供当日分钟线时FAIL是预期的拒绝行为。向开发者提供JSON和日志，核对最新日期、根数和source字段。通过后重启late-session服务加载代码，下次真实管线仍需检查TDX→HTTP切换日志、覆盖率及耗时。公网请求是否可达因环境而异，不能仅凭本地成功保证云端可用。
